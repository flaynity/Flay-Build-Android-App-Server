# Flay AI Android Build Server

Real APK backend for the Build Android App page.

Supports Kotlin Native, Java Native and HTML / Web projects. The server receives the project ZIP generated by Flay AI, extracts it in a temporary isolated directory, runs Gradle assembleDebug with JDK 17 + Android SDK, finds the APK, and returns the APK binary.

## Docker

```bash
docker build -t flay-ai-build-server .
docker run --rm -p 8080:8080 -e BUILD_TOKEN=change-this-token -e ALLOWED_ORIGINS=* flay-ai-build-server
```

Health: GET /health

Build: POST /build with JSON:
```json
{"name":"My App","technology":"kotlin","archiveBase64":"<base64 zip>"}
```

The Flay AI client sends this request shape and accepts an APK binary response.

## Production

Use an isolated VM/container with at least 2 CPU cores, 4 GB RAM and about 10 GB free disk. Keep BUILD_TOKEN enabled and restrict ALLOWED_ORIGINS to the Flay AI origin.

This service executes uploaded Android project code, so do not run it with access to sensitive host files or credentials.
